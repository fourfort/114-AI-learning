# 114-AI-Learning

This repository contains the course assignments, projects, and related materials completed during the **Introduction to Artificial Intelligence course (February - June, 2025, Academic Year 114-2)**.  
The materials are shared for academic and learning purposes, and feedback from teachers, researchers, and fellow learners is sincerely welcome.  

---

## 📂 Repository Contents

The repository covers a variety of AI and machine learning topics, mostly implemented in **Jupyter Notebooks** for ease of use:

- **Linear Regression**: Model building and testing  
- **K-Means Clustering**: Statistical applications and model training using Kaggle datasets (including silhouette coefficient evaluation)  
- **Decision Trees**: Implementation and analysis  
- **Association Rule Mining**: Apriori algorithm applications  
- **Generative Adversarial Networks (GANs)**  
- **Large Language Models (LLMs)**  
- **Web Scraping**: Data collection and processing  

All projects demonstrate the application of machine learning and deep learning techniques in practical scenarios.
